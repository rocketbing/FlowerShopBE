# 邮件发送故障排除指南

## 错误：535-5.7.8 Username and Password not accepted

### 可能的原因和解决方案

#### 1. 未启用两步验证
**症状**：无法生成应用专用密码，或应用专用密码不工作

**解决步骤**：
1. 访问：https://myaccount.google.com/security
2. 找到"两步验证"（2-Step Verification）
3. 如果显示"关闭"或"未启用"，点击"开始使用"
4. 完成两步验证设置
5. **重要**：必须启用传统的"两步验证"，不能只使用 Passkeys

#### 2. 应用专用密码错误或已过期
**症状**：密码看起来正确，但认证失败

**解决步骤**：
1. 访问：https://myaccount.google.com/apppasswords
2. 删除旧的"Flower Shop Backend"应用专用密码
3. 重新生成新的应用专用密码：
   - **应用**：选择"邮件"或"其他（自定义名称）"
   - **设备**：选择"其他（自定义名称）"，输入"Flower Shop Backend"
   - 点击"生成"
4. **立即复制**生成的 16 位密码（格式：`xxxx xxxx xxxx xxxx`）
5. 更新 `.env` 文件中的 `SMTP_PASS`：
   ```env
   SMTP_PASS=xxxx xxxx xxxx xxxx  # 可以去掉空格
   ```
6. 重启服务器

#### 3. 密码中有空格或特殊字符
**症状**：密码复制时可能包含空格

**解决步骤**：
- 确保 `.env` 文件中的密码没有多余的空格
- 可以去掉所有空格，只保留字母和数字
- 例如：`abcd efgh ijkl mnop` 可以写成 `abcdefghijklmnop`

#### 4. 使用了普通密码而不是应用专用密码
**症状**：使用账户登录密码

**解决步骤**：
- ❌ **不要使用**：账户的登录密码
- ✅ **必须使用**：应用专用密码（App Password）
- 应用专用密码是 16 位字符，格式为 `xxxx xxxx xxxx xxxx`

#### 5. 账户被锁定或限制
**症状**：多次认证失败后账户可能被临时锁定

**解决步骤**：
1. 等待 24 小时后重试
2. 检查 Google 账户安全页面是否有安全警告
3. 确认账户未被暂停或限制

### 快速检查清单

- [ ] 已启用两步验证（不是 Passkeys）
- [ ] 已生成应用专用密码（不是普通密码）
- [ ] `.env` 文件中的 `SMTP_PASS` 是正确的应用专用密码
- [ ] 密码中没有多余的空格
- [ ] 邮箱地址 `SMTP_USER` 正确
- [ ] 重启了服务器

### 测试配置

运行测试脚本：
```bash
node scripts/testEmail.js
```

如果仍然失败，检查：
1. 服务器日志中的详细错误信息
2. Google 账户安全页面是否有异常活动
3. 尝试生成新的应用专用密码
